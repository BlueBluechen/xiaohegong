# DESIGN.md · 小小河工 产品介绍

## 0. 设计取向

这套 PPT 的视觉必须**和产品本身一致**——不然封面是对的、里面是另一套，听众会怀疑这两样是不是同一个东西。
所以色板直接用产品 CSS 变量：`#072F35`（深青）/ `#F7F4EC`（米白）/ `#C9A24B`（金）/ `#B5432F`（朱砂）。
字体用宋体标题 + 黑体正文，和界面一致。

画布 1280×720。

## 1. 母版三区

| 区 | 位置 | 高度 | 用途 |
|---|---|---|---|
| A 标题块 | y 0–120 | 120（上 padding 28） | 章节序号 + 主标题 34px |
| B 内容区 | y 120–660 | 540 | 正文、图、卡片 |
| C 页脚条 | y 660–720 | 60 | 左：项目名 12px；右：页码 NN / 06 |

左右 padding 76px（产品界面也是这个量级，保持一致）。
封面与第 6 页可自定义版式；2–5 页严格同母版。

## 2. 色板（4 hex，不增不减）

| 角色 | hex | 用途 |
|---|---|---|
| 主色 深青 | `#072F35` | 封面/深色页背景，标题字（浅色页） |
| 米白 | `#F7F4EC` | 浅色页背景，深色页文字 |
| 金 | `#C9A24B` | 强调：章节序号、锚点数字、细线、CTA |
| 朱砂 | `#B5432F` | 极少量：起点标记、警示/强调点 |

文本灰（非色板，中性色）：深色底上 `#8FB0AE`，浅色底上 `#5C6B6B`。

篇幅比例（色彩分配）：
- P1 封面（hero）：深青 92% + 米白 5% + 金 3%
- P2（supporting）：米白 78% + 深青 16% + 金 4% + 朱砂 2%
- P3（supporting）：米白 82% + 深青 12% + 金 6%
- **P4（hero）**：深青 60% + 米白 28% + 金 10% + 朱砂 2% —— 四张截图是全篇最重的一张图组
- P5（supporting）：米白 80% + 深青 15% + 金 5%
- P6（hero）：深青 88% + 金 8% + 米白 4%

## 4. 装饰白名单

只用三种：
1. **1px 金细线**（`#C9A24B` 40% 透明度）——分隔、标题下的短线
2. **竖排水脉线**——P3 十闸列表左侧那条（直接呼应产品护照页）
3. **朱砂起点圆点**——仅 P3 一处，直径 10px

禁止：阴影卡片、圆角大色块、图标集、渐变球。
产品的界面本身就是纸 + 墨 + 一道金线，PPT 也只用这些。

## 第 2 页改版记录（2026-10-24 晚）

**改动原因**：原第 2 页讲「记录太少、取样稀疏」——是工作者视角，作为开场提问太小。
改为城市视角：一条治理完成、人流已经到位的河，缺的是承载公众参与的载体。

**视觉结构**：标题（治理的终点）→ 客流锚点数字（3000–5000 / 4万+）→ 三块对照
（现在：被治理的河 → 载体：手机/护照/档案 → 之后：公共教育的舞台）→ 结论句。

**为什么把 23.6 公里换成客流数字**：河有多长听众记不住，
「一年上百万人来看这条河」才是能让人坐直的数字。23.6 公里保留在封面与第 3 页。

## 七页定稿（2026-10-24 晚 2）

用户手插回「一条河的六十年」那页，理由是现在这版丢了历史感、流经地域、地理文化。
确认**不合并**，两页各管一件事，只是统一编号与格式。

| # | 文件 | 承担 |
|---|---|---|
| 02 | 02-river.slide | 是什么：历史 / 地理 / 四数字 / 河道走向图 |
| 03 | 03-now.slide | 为什么是现在：客流锚点 / 一次转折 / 一句结论 |

**统一项**：标题块 76/42、序号 13px 金、页码 `NN / 07`、章节序号 01–06。

**P3 减量**：删掉重复的生态数据（鸟 90+ / 鱼 30+ / 保护动物 / 18 处节点，已上移 P2）、
删掉「可游客多看过即走」前的铺陈、删掉「下一步是公共化」那句副文。
现在只剩：两个客流数字 → 三块对照 → 一句结论。

**P2 主视觉**：用户提供的河道走向图（RGBA 透明，2000×1200）。
必须用**原图**——任何重编码都会把透明区变黑。容器 700×420 溢出右边界，水从画面外流进来。
