# 小小河工 · 竖版交互 Demo

一条手机端的巡河 Demo：单文件、零依赖、无图片资源，双击 `demo.html` 即可打开。

## 这是什么

给 8–12 岁孩子的公民河流教育产品原型。以北京清河 23.6 公里干流、十座水闸为骨架，
把一个孩子的巡河行为拆成三件互不打扰的事：

| 动线 | 依赖 | 产出 |
|---|---|---|
| **巡河**（现场出勤） | 需要到达点位 | 带坐标的结构化记录 + 印章 |
| **记录**（公开 UGC） | 无 | 按点位聚合的全河记录流 |
| **探索**（AI 科普） | 无 | 自然笔记（无坐标，不进数据集） |
| **护照** | 无 | 身份、职级、里程、两类计数 |

## 打开方式

```bash
open demo.html
```

支持 hash 深链，方便截图与演示：

| 路由 | 屏幕 |
|---|---|
| `#map` | 巡河路线（培训模式） |
| `#field` | 巡河路线（现场模式，需到达验证） |
| `#arrive` | 到达验证 |
| `#records` | 记录（按点位排） |
| `#detail` | 记录详情（含同点位对比） |
| `#explore` | 探索入口 |
| `#explore2` | 探索知识卡 |
| `#notes` | 自然笔记 |
| `#passport` | 河工护照 |

加 `?static=1` 可关闭所有过渡动画，便于无头截图。

## 怎么构建

`demo.html` 是生成产物，不要直接改它。

```bash
python3 build_demo.py
```

它做两件事：

1. 从 `demo.template.html` 抽出 `GATES`（十座闸的真实数据）和 `META`（每站的题目与任务），
   注入 `demo-m.template.html` 的 `/*__DATA__*/` 占位符；
2. 施加若干版式微调（封面步骤条、教练提示位置等）。

## 数据模型

一条记录是这套东西的核心：

```
点位 / 时间 / 类型 / 观测 / 证据 / 环境 / 观察者 / 许可
```

外加一个 `source` 字段区分两条互不污染的数据流：

- `field` —— 现场出勤，有坐标，进数据集
- `explore` —— 自由探索，无坐标，只做科普

研究机构只认 `field`，`explore` 才是让人每天打开的理由。
